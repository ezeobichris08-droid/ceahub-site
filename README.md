# Chivary EA Hub — CEA Hub

Static front-facing website for Chivary EA Hub.

## Main files

- `index.html` — home
- `about.html` — company/brand overview
- `ecosystem.html` — CEA Hub architecture
- `products.html` — products coming soon
- `assets/style.css` — complete visual styling
- `assets/site.js` — loading screen, mobile navigation and scroll effects
- `assets/chivary-emblem.png` — supplied brand emblem
- `CNAME` — custom GitHub Pages domain

This is framework-free HTML/CSS/JavaScript, so it can be hosted directly with GitHub Pages.
